# 📁 Data Folder

This folder contains the dataset used for Marketing Funnel & Conversion Analysis (Task 3).

---

## 📊 Dataset Description
The dataset includes marketing campaign data such as:
- Customer job type
- Campaign contacts
- Previous campaign outcome
- Conversion status (deposit or not)
- Duration of engagement

---

## 🎯 Purpose
This data is used to analyze:
- Marketing funnel performance
- Conversion rates
- Customer response behavior
- Campaign effectiveness

---

## 🛠 Usage
The dataset is analyzed using:
- Microsoft Excel
- Pivot Tables
- Charts & Funnel Analysis

---

## 📌 Outcome
This dataset helps understand how users move through the marketing funnel and identify key factors affecting conversion success.
